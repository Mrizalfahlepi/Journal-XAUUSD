2. PERTAHANKAN LOGIKA PERHITUNGAN
=================================

Implementasikan logika berikut secara akurat.

Profit Aktual Rupiah:

Profit_Rp = Profit_USC × Kurs

Saldo Aktual USC:

Saldo_USC = Modal_Awal + SUM seluruh Profit Aktual USC sampai hari tersebut.

Saldo Aktual Rupiah:

Saldo_Rp = Saldo_USC × Kurs

Profit %:

Profit_% = Profit_Aktual_USC / Saldo_sebelum_profit_USC

Jangan menggunakan rumus yang menghasilkan denominator salah.

Target Profit hari pertama:

Target_Profit_1 = Modal_Awal × Target_%

Target Saldo hari pertama:

Target_Saldo_1 = Modal_Awal + Target_Profit_1

Target Profit hari berikutnya:

Target_Profit_hari_ini =
Target_Saldo_hari_sebelumnya × Target_%

Target Saldo:

Target_Saldo_hari_ini =
Target_Saldo_hari_sebelumnya + Target_Profit_hari_ini

Dengan kata lain, target menggunakan sistem compound growth.

Contoh jika target = 5%:

Hari 1:
2503 × 5%

Hari 2:
Target saldo hari 1 × 5%

Hari 3:
Target saldo hari 2 × 5%

dan seterusnya.

Status:

Jika Profit_% >= Target_%:
status = tercapai

Jika Profit_% < Target_%:
status = belum tercapai

Jika Profit belum diisi:
status = kosong.
